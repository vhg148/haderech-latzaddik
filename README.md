# הדרך לצדיק — אזמרה ראן ✈️🔥

משחק ריצה תלת־ממדי (3D) בדפדפן בסגנון *Subway Surfers* בהשראת תורת **רבי נחמן מברסלב**:

- **✦ נקודות טובות (תורה רפ״ב — אזמרה)**: אוספים נקודות טובות, בונים רצף ניגון וממלאים מד **שמחה תמיד**.
- **🌩️ המניעות**: סופת מניעות רודפת אחריך; 3 כוחות עמידה (`💛💛💛`) ומנגנון **"אין שום יאוש בעולם כלל"** לשבירת מניעה והתחזקות.
- **✈️ 3 שלבים עד לטיסה לאומן (שער רפ״ב)**:
  1. שדרות ירושלים
  2. גשר צר מאד (`×2` נקודות)
  3. טרמינל נתב״ג ומסלול ההמראה עד המטוס!
- **🔥 כוחות וחיזוקים**: כובע האש, מגנט אזמרה, כנפי שמחה, אור הצדיק (`×2`) וחנות שדרוגים.

## שליטה
- `⬅️` / `➡️` או `A` / `D` (או החלקה) — החלפת נתיב
- `⬆️` / `W` / `Space` (או החלקה למעלה) — קפיצה
- `⬇️` / `S` (או החלקה למטה) — החלקה / נחיתה מהירה
- `E` / `Shift` — הפעלת **שמחה תמיד** (מעל 80%)
- `P` / `Esc` — השהייה • `M` — השתקה

## הפעלה מקומית
```bash
npm start
```
